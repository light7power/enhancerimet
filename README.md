# DingTalk Enhancement Modern

钉钉增强模块，适用于 `com.alibaba.android.rimet`。

## 功能

- 消息防撤回：保留文本、图片、文件、语音等类型的原消息。
- 撤回提示：在会话中显示居中的系统提示，包含撤回者名称和“已阻止”状态。
- 屏蔽已读：阻止向会话发送已读状态。
- 支持生成本机配置和尝试修复插件。

## 测试版本

已测试版本：`Rimet 8.5.5 / versionCode 1274`。

其他版本请自行测试。

## 已知问题

- 对方撤回消息的保留功能目前可用。
- 部分场景下，自己撤回消息仍可能停留在“消息撤回中…”，该问题尚未彻底解决。
- 本项目公开接受问题反馈、日志、调用链分析和修复方案，欢迎提交 Issue 或 Pull Request 协助解决。

提交问题时请尽量注明钉钉版本、消息类型、单聊或群聊、是否在聊天前台，以及 LSPosed日志等。
